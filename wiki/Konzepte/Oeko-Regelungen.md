# Öko-Regelungen (1. Säule)

Die Öko-Regelungen (ÖR) sind freiwillige, einjährige Maßnahmen der 1. Säule der GAP. Sie können teilweise mit FAKT II-Maßnahmen (2. Säule) kombiniert werden.

## Übersicht

| Code | Maßnahme | Prämie |
|------|----------|--------|
| ÖR 1a | Nichtproduktive Flächen auf Ackerland | 1.300/500/300 €/ha |
| ÖR 1b | Blühstreifen/-flächen auf Ackerland | 150 €/ha |
| ÖR 1c | Blühstreifen/-flächen in Dauerkulturen | 150 €/ha |
| ÖR 1d | Altgrasstreifen/-flächen in Dauergrünland | 900/400/200 €/ha |
| ÖR 2 | Anbau vielfältiger Kulturen | variabel |
| ÖR 3 | Agroforstliche Bewirtschaftung | variabel |
| ÖR 4 | Extensivierung des gesamten Dauergrünlands | variabel |
| ÖR 5 | Dauergrünland mit mind. 4 Kennarten | variabel |
| ÖR 6 | PSM-Verzicht auf Acker/Dauerkulturen | variabel |
| ÖR 7 | Natura 2000-angepasste Bewirtschaftung | variabel |

## Kombinierbarkeit mit FAKT II

Die Kombinierbarkeit ist in der [[Kombinationstabelle]] detailliert dargestellt. Wichtige Regeln:

- **X** = kombinierbar
- **-** = nicht kombinierbar (auf derselben Fläche)
- **kR** = keine Kombination, da Rechtsgrundlage es ausschließt
- **(o)** = B6 nur in Kombination mit anderer FAKT-GL-Maßnahme
- **x/a** = kombinierbar, aber mit Abzug

*Siehe auch: [[Kombinationstabelle]], [[Konditionalitaet]]*
